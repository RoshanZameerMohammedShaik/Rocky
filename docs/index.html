Features

Everything runs locally

Rocky embeds its own AI engine. No background services, no separate apps, no internet required after install.

🧠

Embedded AI Engine

Runs Qwen2.5 models via llama.cpp directly in-process. No Ollama, no LM Studio, no background service eating your RAM.

📁

File Operations

Read, write, edit, search, and list files. Rocky handles CRUD with diff previews and safety checks.

💻

Shell Commands

Execute terminal commands with a permission system. Dangerous commands are flagged before execution.

🌐

Web Search

Search DuckDuckGo and fetch web pages. Works when online, gracefully handles offline mode.

🔀

Git Integration

Check status, view diffs, browse logs, and create commits directly from the conversation.

📚

Knowledge Base

Index your files into a searchable knowledge base. Rocky remembers your codebase.

⚡

GPU Auto-Detection

Automatically uses Metal on macOS, CUDA on NVIDIA, Vulkan on AMD. Falls back to CPU gracefully.

💾

Session Management

Save and resume conversations. Pick up exactly where you left off.

🎧

Audio Transcription

Transcribe audio files with Whisper. Optional install, works offline once set up.

Philosophy

What Rocky is (and isn't)

Rocky has strong opinions about what a local AI assistant should be.

✅ What Rocky Does

  • ✓ Runs 100% on your machine — your data never leaves
  • ✓ Works offline after first model download
  • ✓ Installs with one command: pip install .
  • ✓ Launches with one command: Rocky
  • ✓ Auto-downloads its AI model on first run
  • ✓ Reads, writes, and edits your files
  • ✓ Runs shell commands with your permission
  • ✓ Uses your GPU automatically if available
  • ✓ Asks before doing anything dangerous

❌ What Rocky Doesn't Do

  • ✗ No cloud — zero data sent to any server
  • ✗ No API keys or accounts required
  • ✗ No Ollama or external AI apps installed
  • ✗ No background services eating your RAM
  • ✗ No telemetry or usage tracking
  • ✗ No system tray icons or hidden UI
  • ✗ No internet required after setup
  • ✗ No subscription or paid tier
  • ✗ Never runs commands without your approval
Get Started

Install in 60 seconds

Clone, install, run. Works on macOS, Windows, and Linux.

1

Clone & Install

Requires Python 3.10+. This installs Rocky and its embedded AI engine.

$ git clone https://github.com/RoshanZameerMohammedShaik/Rocky.git
$ cd Rocky
$ pip install .
2

Run Rocky

On first run, Rocky auto-downloads its AI model (~2.2 GB). After that, it works fully offline.

$ Rocky
✨

That's it

No configuration needed. No accounts. No API keys. Just start chatting.

Platform-specific notes

# macOS — Metal GPU acceleration works automatically
$ pip install .

# Windows/Linux with NVIDIA GPU — for CUDA acceleration
$ CMAKE_ARGS="-DGGML_CUDA=on" pip install .

# All platforms: Python 3.10+ required
Usage

Commands & Controls

Rocky uses slash commands for built-in operations. Everything else is natural conversation.

Command Description
/help Show all available commands
/quit Exit Rocky (also: /exit)
/exit Exit Rocky
/clear Clear conversation history
/save [name] Save current session to disk
/load <name> Load a previously saved session
/sessions List all saved sessions
/model Show current model info
/models List available models with download status
/trust Enable trust mode — skip permission prompts for session
/version Show Rocky version

Safety

Permission System

Rocky never runs commands without asking. Dangerous operations get an extra warning.

Rocky.AI — Permission Request
Rocky.AI wants to run:
$ rm -rf ./build/
⚠ Recursive deletion with wildcard
 
[A]llow once  ·  [T]rust for session  ·  [D]eny
Your choice: a
  • Allow once Run this single command, ask again next time
  • Trust session Skip all permission prompts for the rest of this session
  • Deny Block the command — Rocky will suggest alternatives
